1. Для чого потрібні окремі файли?

HTML відповідає за структуру та вміст вебсторінки. Для оформлення сторінок використовують CSS, а для додаткової поведінки та взаємодії — JavaScript.

Зазвичай ці частини зберігають в окремих файлах, а потім підключають до HTML-документа.

ФайлДля чого потрібенПриклад розширення
HTMLСтруктура сторінки.html
CSSОформлення сторінки.css
JavaScriptДодаткова поведінка та функціональність.js
Запам'ятай: сьогодні ми вчимося саме підключати CSS- і JavaScript-файли. Детально вивчати самі мови CSS та JavaScript будемо окремо.

2. Підключення CSS — тег link

Для підключення зовнішнього CSS-файлу використовують одиночний тег link. Його розміщують усередині head.

<head>
    <meta charset="UTF-8">
    <title>Мій сайт</title>
    <link rel="stylesheet" href="css/style.css">
</head>

Розглянемо атрибути:

  • rel="stylesheet" — повідомляє браузеру, що підключається таблиця стилів.
  • href="css/style.css" — шлях до CSS-файлу.
Що відбувається?

Браузер знаходить файл style.css у папці css і підключає його до сторінки.

Важливо: link — одиночний тег. Закривальний тег </link> не потрібен.

Якщо CSS-файл лежить поруч з index.html

<link rel="stylesheet" href="style.css">

Якщо CSS-файл лежить у папці css

<link rel="stylesheet" href="css/style.css">

3. Підключення JavaScript — тег script

Для підключення зовнішнього JavaScript-файлу використовують тег script з атрибутом src.

<body>
    <h1>Моя сторінка</h1>
    <p>Вітаю на сайті!</p>

    <script src="js/main.js"></script>
</body>
  • src — шлях до JavaScript-файлу.
  • js/main.js — файл main.js, який знаходиться в папці js.
Де розміщувати script?

Рекомендовано розміщувати підключення зовнішнього скрипту наприкінці body, перед закривальним тегом </body>. Так основний вміст сторінки встигає завантажитися до обробки скрипту.

Не переплутай: на відміну від link, тег script має відкривальну та закривальну частини: <script ...></script>.

Чи можна написати JavaScript прямо в HTML?

<script>
    // Тут може бути JavaScript-код
</script>

Так, тег script як і стилі через тег style можна поміщати в html-файлі. Але в цьому уроці ми тренуємо підключення окремих файлів.

4. Структура папок проєкту

Приклад організації файлів:

мій-сайт/
│
├── index.html
│
├── css/
│   └── style.css
│
└── js/
    └── main.js

У файлі index.html підключення виглядатимуть так:

<head>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <!-- Вміст сторінки -->

    <script src="js/main.js"></script>
</body>
Пам'ятай про шлях: якщо HTML-файл знаходиться в кореневій папці проєкту, то для входу в папку css записуємо css/, а для входу в js — js/.

Якщо файли style.css і main.js поки порожні, зовнішній вигляд та поведінка сторінки не зміняться. Але підключення вже налаштоване.

🎯 Міні-завдання 1 — «Підключи файли»

  1. Створи папку проєкту my-site.
  2. У ній створи файл index.html.
  3. Створи папку css, а в ній файл style.css.
  4. Створи папку js, а в ній файл main.js.
  5. Усередині тегу head підключи CSS за допомогою тегу link.
  6. Перед закривальним тегом body підключи JavaScript за допомогою тегу script.
  7. Додай на сторінку заголовок та два абзаци.
  8. Перевір, чи немає помилок у назвах папок і шляхах до файлів.

Додатково: відкрий HTML-файл у браузері. Переконайся, що сторінка відображається, навіть якщо файли CSS і JS поки порожні.

5. Тег div — блок

Тег div створює блок — контейнер, у який можна помістити інші HTML-елементи.

<div>
    Це перший блок
</div>

<div>
    Це другий блок
</div>
Це перший блок
Це другий блок

Кожен div починається з нового рядка та займає доступну ширину.

Усередину div можна поміщати заголовки, абзаци, зображення, списки, посилання та інші елементи.

<div>
    <h3>Мій улюблений предмет</h3>
    <p>Мені подобається інформатика.</p>
</div>

Мій улюблений предмет

Мені подобається інформатика.

Для чого використовують div? Щоб об'єднувати елементи в логічні блоки: шапку сайту, меню, основну частину, картки, підвал тощо.

6. Тег span — рядковий елемент

Тег span виділяє частину тексту або інший невеликий рядковий фрагмент. Сам по собі він не переносить текст на новий рядок.

<p>
    Сьогодні ми вивчаємо
    <span>HTML</span>.
    Слово HTML залишається всередині того самого рядка.
</p>

Сьогодні ми вивчаємо HTML.

Слово HTML залишається всередині того самого рядка.

Тег span зручно використовувати, коли потрібно виділити лише частину речення, щоб згодом оформити її за допомогою CSS.

<p>
    Моя оцінка з інформатики:
    <span>12 балів</span>.
</p>

Моя оцінка з інформатики: 12 балів.

Запам'ятай: span не створює окремий блок. Він виділяє частину рядка.

7. Порівняння div і span

ТегТип елементаЯк відображаєтьсяДля чого зручно використовувати
divБлоковийПочинається з нового рядкаГрупування великих частин сторінки
spanРядковийЗалишається в поточному рядкуВиділення частини тексту або фрагмента

Приклад для порівняння

<p>Перший текст <span>виділений фрагмент</span> продовження тексту.</p>

<div>Перший блок</div>
<div>Другий блок</div>

Перший текст виділений фрагмент продовження тексту.

Перший блок
Другий блок

🎯 Міні-завдання 2 — «Інформаційна картка»

Створи сторінку про улюблену гру, фільм, музичний гурт, смартфон або майбутню професію.

  1. Додай головний заголовок сторінки.
  2. Створи за допомогою div три окремі блоки: «Коротко про тему», «Цікаві факти», «Моя думка».
  3. У кожному блоці використай заголовок і хоча б один абзац.
  4. У тексті одного з абзаців виділи за допомогою span важливе слово або фразу.
  5. Додай ще один div для підсумку сторінки.

Додатково: підключи до сторінки порожні файли style.css і main.js за правилами з першої частини уроку.

📚 Підсумок уроку

link — підключає зовнішній CSS-файл у head.

script — підключає JavaScript-файл; у нашому прикладі розміщуємо його наприкінці body.

div — блочний контейнер для групування елементів.

span — рядковий контейнер для виділення частини тексту.
