1. Списки

HTML дозволяє створювати два основні типи списків: нумеровані та ненумеровані.

Нумерований список — <ol> + <li>

ol створює список із порядковими номерами, а кожен пункт записується за допомогою li. 

<ol>
  <li>Перший пункт</li>
  <li>Другий пункт</li>
  <li>Третій пункт</li>
</ol>

Як це виглядатиме:

  1. Перший пункт
  2. Другий пункт
  3. Третій пункт

Атрибут start

За допомогою start можна вказати, з якого номера починатиметься список. 

<ol start="3">
  <li>Третій пункт</li>
  <li>Четвертий пункт</li>
  <li>П'ятий пункт</li>
</ol>
  1. Третій пункт
  2. Четвертий пункт
  3. П'ятий пункт

Атрибут type

Атрибут type змінює вигляд нумерації.

Значення Результат
type="1" 1, 2, 3...
type="A" A, B, C...
type="I" I, II, III... 
<ol type="A">
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>

<ol type="I">
  <li>Перший розділ</li>
  <li>Другий розділ</li>
  <li>Третій розділ</li>
</ol>

Як це виглядатиме:

  1. HTML
  2. CSS
  3. JavaScript
  1. Перший розділ
  2. Другий розділ
  3. Третій розділ

Ненумерований список — <ul> + <li>

У ненумерованому списку замість номерів використовуються маркери.

<ul>
  <li>Ноутбук</li>
  <li>Смартфон</li>
  <li>Навушники</li>
</ul>

Як це виглядатиме:

  • Ноутбук
  • Смартфон
  • Навушники

Атрибут type для ul

<ul type="circle">
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

<ul type="square">
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

Як це виглядатиме:

  • Пункт 1
  • Пункт 2
  • Пункт 1
  • Пункт 2

Вкладені списки

Список можна розміщувати всередині іншого списку. Це дозволяє створювати ієрархію. 

<ul>
  <li>Комп'ютерні науки
    <ul>
      <li>Програмування</li>
      <li>Веброзробка</li>
      <li>Бази даних</li>
    </ul>
  </li>
  <li>Мультимедіа</li>
</ul>

Як це виглядатиме:

  • Комп'ютерні науки
    • Програмування
    • Веброзробка
    • Бази даних
  • Мультимедіа
Спробуй сам: зроби список «Мої захоплення», а всередині одного пункту створи вкладений список.

2. Атрибути

Атрибут — додаткова характеристика HTML-тега. Він записується всередині відкривального тега: 

<тег атрибут="значення">Текст</тег>

Атрибут title

title можна додавати до багатьох HTML-тегів. Зазвичай він створює підказку при наведенні курсора. 

<p title="Це підказка до абзацу!">
  Наведи курсор на цей текст і побачиш підказку, сховану в атрибуті цього тегу.
</p>

Як це працює:

Наведи курсор на цей текст і побачиш підказку, сховану в атрибуті цього тегу.

Атрибут lang

lang застосовують до тега <html>, щоб вказати мову документа. 

<html lang="uk">
Для української мови використовуємо lang="uk". Це корисно для пошукових систем, засобів доступності та програм озвучення.

Тег <meta>

meta містить службову інформацію про вебсторінку. Сам по собі він не відображає текст на сторінці — його властивості задаються атрибутами. 

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Опис моєї сторінки">
Запис Для чого
charset="UTF-8" Вказує кодування документа.
name="viewport" Допомагає правильно відображати сторінку на різних екранах.
name="description" Містить короткий опис сторінки.

3. Посилання

Основний тег для створення посилань — <a>.

Атрибут href

У href вказується адреса, куди веде посилання.

<a href="https://www.google.com">
  Відкрити Google
</a>

Як це виглядатиме:

Відкрити Google

Внутрішні та зовнішні посилання

  • Зовнішнє веде на інший сайт.
  • Внутрішнє веде на іншу сторінку твого сайту.
<!-- Зовнішня сторінка -->
<a href="https://www.wikipedia.org">Wikipedia</a>

<!-- Інша сторінка нашого сайту -->
<a href="about.html">Про нас</a>

Атрибут target

Значення Що відбувається
target="_self" Посилання відкривається у поточній вкладці.
target="_blank" Посилання відкривається в новій вкладці. 
<a href="about.html" target="_self">Про нас</a>

<a href="https://www.wikipedia.org" target="_blank">
  Wikipedia
</a>

Атрибут title у посиланні

<a href="https://www.wikipedia.org"
   title="Перейти до Wikipedia"
   target="_blank">
  Wikipedia
</a>
Wikipedia

Посилання на електронну адресу

Якщо в href написати mailto:, браузер спробує відкрити програму електронної пошти. 

<a href="mailto:somemail@dot.com">
  Написати нам на електронну пошту
</a>
Написати нам на електронну пошту

Якірні посилання — перехід до частини сторінки

Щоб перейти до конкретного місця на поточній сторінці, елементу задають id, а в атрибуті href пишуть # і вказуть це значення з ідентифікатора елемента, на якого хочуть перейти. 

<h2 id="contacts">Контакти</h2>

...

<a href="#contacts">Перейти до контактів</a>

Як це працює:

🔗 Перейти до розділу «Списки»

А ось цей абзац має id="anchor-example".

🔗 Перейти до цього місця
Запам'ятай: id — унікальне ім'я елемента, а #id у href — звернення до цього елемента.

🎯 Практичне завдання

«Створи власний тематичний сайт»

Створи односторінковий HTML-сайт на одну з тем. Кожен великий розділ сторінки повинен бути окремою частиною сайту.

💡 Варіанти тем

  • 🎮 Моя улюблена відеогра — сюжет, персонажі, світ гри, цікаві факти.
  • 🤖 Штучний інтелект — що це таке, де використовується, переваги та ризики.
  • 🚀 Освоєння космосу — планети, космічні місії, майбутнє людства.
  • 🎵 Музика, яку я слухаю — жанри, виконавці, альбоми, рекомендації.
  • 🏎️ Світ автомобілів — історія, цікаві моделі, технології майбутнього.
  • 💻 Професії майбутнього — які професії можуть стати популярними через 10–20 років.
  • 🌍 Місце, яке я хочу відвідати — країна, місто, пам'ятки, цікаві факти.
  • 🧠 Як працює мозок — пам'ять, сон, навчання та цікаві факти.

Частина 1. Односторінковий сайт

Створи сторінку з щонайменше 4–5 розділами. Кожен розділ повинен мати свій заголовок.

Обов'язково використай:

  1. <h1>, <h2>, <h3>;
  2. <p> для тексту;
  3. нумерований список <ol>;
  4. ненумерований список <ul>;
  5. хоча б один вкладений список;
  6. start та один із варіантів type для ol;
  7. type="circle" або type="square" для ul;
  8. атрибут title хоча б для одного елемента;
  9. зовнішнє посилання з href;
  10. посилання з target="_blank";
  11. посилання на електронну адресу через mailto:;
  12. щонайменше 3 якірні посилання за допомогою id та #.

Частина 2. Перетвори сайт на багатосторінковий

Перероби роботу так, щоб інформація була розподілена між кількома HTML-файлами. 

index.html      — головна сторінка
history.html    — історія
facts.html      — цікаві факти
gallery.html    — галерея
contacts.html   — контакти

На кожній сторінці зроби навігацію за допомогою <a>, щоб можна було переходити між сторінками.

⭐ Додаткове завдання

  • Зроби на кожній сторінці посилання «На головну».
  • Додай якір «На початок сторінки».
  • Використай різні види списків залежно від змісту.
  • Додай title до кількох посилань.

✅ Самоперевірка

  • ☐ Я знаю різницю між ol і ul.
  • ☐ Я вмію створювати вкладені списки.
  • ☐ Я вмію використовувати start і type.
  • ☐ Я розумію, що таке атрибут HTML-тега.
  • ☐ Я знаю, для чого потрібні title, lang і meta.
  • ☐ Я вмію створювати зовнішні та внутрішні посилання.
  • ☐ Я вмію відкривати посилання в новій вкладці.
  • ☐ Я вмію створювати посилання на електронну пошту.
  • ☐ Я вмію створювати якірні посилання за допомогою id та #.
  • ☐ Я можу створити багатосторінковий сайт.
Головне: не просто копіюй приклади. Експериментуй зі значеннями атрибутів і перевіряй результат безпосередньо у браузері.
