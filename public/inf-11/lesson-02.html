HTML: теги для роботи з текстом

Урок №2 • 11-А клас • HTML5

🎯 Мета уроку

Навчитися використовувати HTML-теги для створення та форматування текстового вмісту вебсторінки.

Після уроку ви повинні вміти:

  • створювати заголовки різних рівнів;
  • оформлювати абзаци та переносити рядки;
  • виділяти важливий текст;
  • створювати цитати, код, верхні та нижні індекси;
  • комбінувати різні теги для створення цікавої вебсторінки.

1. Заголовки

Для заголовків використовують теги від <h1> до <h6>.

h1 — головний заголовок

h2 — заголовок розділу

h3 — підрозділ

h4 — менший підрозділ

h5 — невеликий заголовок
h6 — найменший заголовок
<h1>Моя вебсторінка</h1>
<h2>Проєкти</h2>
<h3>Мій перший проєкт</h3>
Порада: зазвичай на сторінці використовують один основний h1, а далі будують логічну структуру за допомогою h2, h3 тощо.

2. Абзаци та перенесення рядка

Тег Призначення Приклад
<p> Абзац тексту <p>Це мій абзац.</p>
<br> Примусовий перенос рядка Рядок 1<br>Рядок 2
<hr> Горизонтальна тематична лінія <hr>

Перший абзац. Тут міститься звичайний текст.

Другий абзац.
А цей текст починається з нового рядка.

3. Виділення тексту

Тег Що робить Приклад
<strong> Позначає важливий текст дуже важливо
<b> Візуально робить текст жирним жирний текст
<em> Логічно виділяє текст, зазвичай курсивом важливий акцент
<i> Курсивне оформлення курсив
<u> Підкреслений текст підкреслено
<s> Текст, який більше не є актуальним Стара ціна: 500 грн
<mark> Підсвічує фрагмент головне слово
<small> Дрібніший текст Примітка 
<p>
  Це <strong>дуже важливо</strong>,
  а це <em>акцент</em>.
  <mark>Зверни увагу!</mark>
</p>

Це дуже важливо, а це акцент. Зверни увагу!

4. Верхній та нижній індекси

Теги <sup> та <sub> дозволяють створювати верхні та нижні індекси.

Приклади:

  • Площа: 10 м2
  • Вода: H2O
  • Теорема: a2 + b2 = c2
  • Вуглекислий газ: CO2
H<sub>2</sub>O
x<sup>2</sup>
a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup>

H2O

x2

a2 + b2 = c2

5. Цитати

Для цитат можна використовувати <q> та <blockquote>.

Коротка цитата: Знання — сила.

HTML визначає структуру вебсторінки, а CSS відповідає за її оформлення. 
<p>Як казав автор: <q>Знання — сила.</q></p>

<blockquote>
  Довша цитата або окремий фрагмент тексту.
</blockquote>

6. Код та попередньо форматований текст

<code> використовують для невеликих фрагментів програмного коду.

Наприклад: console.log("Hello!");

<pre> зберігає пробіли та переноси рядків.

<pre>function hello() {
    console.log("Привіт, світе!");
}</pre>

7. Список тегів для сьогоднішньої роботи

<h1>–<h6> <p> <br> <hr> <strong> <b> <em> <i> <u> <s> <mark> <small> <sup> <sub> <q> <blockquote> <code> <pre>

🎬 Практичне завдання

«Створи свою сторінку про космічну експедицію» 🚀

Уяви, що ти учасник першої української експедиції на Марс. Створи HTML-сторінку, яка розповідає про місію, космічний корабель, екіпаж і цікаві факти про Марс.

Обов'язково використай:

  1. Заголовки — щонайменше 3 рівні: h1, h2, h3.
  2. Абзаци — не менше 5 тегів p.
  3. Виділення — використай щонайменше 5 різних тегів із групи strong, b, em, i, u, s, mark, small.
  4. Переноси та розділення — використай br та hr.
  5. Формули або хімічні формули — використай sup та sub. Наприклад: CO2, H2O, 210.
  6. Цитату — використай q або blockquote.
  7. Фрагмент коду — використай code або pre. Наприклад, код запуску бортового комп'ютера.

Додатково ⭐

  • Додай зображення Марса або космічного корабля.
  • Створи список членів екіпажу.
  • Додай посилання на цікавий сайт про космос.
  • Додай власний CSS, щоб сторінка виглядала як сайт космічної місії.

✅ Самоперевірка

Перед здачею роботи перевір:

  • ☐ Є <h1> та кілька підзаголовків.
  • ☐ Є щонайменше 5 абзаців.
  • ☐ Використано багато різних тегів форматування.
  • ☐ Є <br> та <hr>.
  • ☐ Є верхній та нижній індекси.
  • ☐ Є цитата.
  • ☐ Є фрагмент коду.
  • ☐ Теги правильно відкриті та закриті.
  • ☐ Файл збережено з розширенням .html.
Головне правило: не потрібно просто копіювати приклади. Зміст сторінки, назви, факти та оформлення придумай самостійно.

🏆 Для тих, хто хоче більше

Спробуй зробити сторінку такою, щоб вона виглядала як справжній сайт космічної місії. Додай кольори, фон, зображення, таблицю характеристик корабля та навігацію між розділами.
